# Compras V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the shopping feature with editable categories (DB table per home), item notes, room filter, product catalog autocomplete (~300 items), and named lists/templates with optional reorder cadence.

**Architecture:** Seven sequential tasks from DB schema → permissions cleanup → backend → UI → named lists → category management UI. The migration (Task 1) replaces the `shopping_category` enum FK on `shopping_items` with a UUID FK to a new `shopping_categories` table; Tasks 2–4 update the existing items flow; Tasks 5–6 add named lists; Task 7 adds category management UI.

**Tech Stack:** Next.js 16 App Router, React 19, Supabase (PostgreSQL + RLS), Zod 4, Vitest, TypeScript

**Spec:** Derived from conversation — no separate spec file.

## Global Constraints

- Zod 4 schema errors: `{ error: "..." }` syntax, NOT `message:` — e.g. `z.string().min(1, { error: "Nome obrigatório" })`
- Server actions: always derive `home_id` from `profiles.current_home_id` server-side; never accept from client
- Server-only query files start with `import "server-only"`; action files use `"use server"` directive
- Supabase types regenerated with: `npx supabase gen types typescript --local > src/types/database.ts 2>/dev/null` (Bash, not PowerShell)
- `textField(fd, "field_name")` helper for FormData extraction
- `fieldErrorsFrom(parsed.error)` for Zod errors; `initialFormState` and `FormState` from `@/features/auth/form-state`
- `requireUser()` from `@/lib/auth/require-user`; `createClient()` from `@/lib/supabase/server`
- `getMemberPermissions` from `@/features/members/permissions` — after Task 2, `shopping_categories: string[]` is removed from its return type
- Use `.select("id")` on UPDATE/DELETE to detect 0-row misses (error:null but empty array = not found)
- Migrations run with: `npx supabase db reset` (Bash only, not PowerShell)
- No push, PR, deploy, or remote operations

## Review Focus

- **category_id nullable**: if a category is deleted, `shopping_items.category_id` becomes null — UI must render "Sem categoria" gracefully everywhere (item row, edit form)
- **applyList batch insert**: each shopping_items INSERT should not block others; verify all items are added even if one fails RLS
- **Autocomplete category auto-fill**: if catalog item's `category_slug` doesn't match any home category's `default_slug`, fall back silently (don't set category_id) rather than erroring
- **Reorder cadence with null last_added_at**: display "Nunca adicionado" rather than NaN/negative date diff
- **Named lists section creation flow**: the "Nova lista" button must be always visible so users can create their first list

```sql
-- shopping_categories
CREATE TABLE shopping_categories (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  home_id uuid NOT NULL REFERENCES homes(id) ON DELETE CASCADE,
  name text NOT NULL CHECK (char_length(trim(name)) BETWEEN 1 AND 50),
  icon text NOT NULL DEFAULT '🛒',
  sort_order int NOT NULL DEFAULT 0,
  default_slug text,
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX idx_shopping_categories_home_id ON shopping_categories(home_id);
ALTER TABLE shopping_categories ENABLE ROW LEVEL SECURITY;
CREATE POLICY "home members full access" ON shopping_categories
  USING (EXISTS (SELECT 1 FROM home_members hm
    WHERE hm.home_id = shopping_categories.home_id AND hm.user_id = auth.uid()))
  WITH CHECK (EXISTS (SELECT 1 FROM home_members hm
    WHERE hm.home_id = shopping_categories.home_id AND hm.user_id = auth.uid()));
GRANT SELECT, INSERT, UPDATE, DELETE ON shopping_categories TO authenticated;

-- New columns on shopping_items
ALTER TABLE shopping_items
  ADD COLUMN category_id uuid REFERENCES shopping_categories(id) ON DELETE SET NULL,
  ADD COLUMN notes text CHECK (char_length(notes) <= 200),
  ADD COLUMN room_id uuid REFERENCES rooms(id) ON DELETE SET NULL;

-- Seed default categories for all homes + migrate existing items
DO $$
DECLARE
  h uuid;
  slugs  text[] := ARRAY['alimentacao','higiene','limpeza','lavanderia','bebe','pet','saude','cozinha','outros'];
  names  text[] := ARRAY['Alimentação','Higiene','Limpeza','Lavanderia','Bebê','Pet','Saúde','Cozinha','Outros'];
  icons  text[] := ARRAY['🍎','🧴','🧹','🧺','🍼','🐾','🩹','🍳','📦'];
  i int;
  new_id uuid;
  slug_map JSONB;
BEGIN
  FOR h IN SELECT id FROM homes LOOP
    slug_map := '{}'::JSONB;
    FOR i IN 1..array_length(slugs, 1) LOOP
      INSERT INTO shopping_categories(home_id, name, icon, sort_order, default_slug)
        VALUES (h, names[i], icons[i], i, slugs[i])
        RETURNING id INTO new_id;
      slug_map := jsonb_set(slug_map, ARRAY[slugs[i]], to_jsonb(new_id::text));
    END LOOP;
    -- Migrate existing items (enum casts to text in PG)
    UPDATE shopping_items
      SET category_id = (slug_map->>(category::text))::uuid
      WHERE home_id = h AND category IS NOT NULL;
  END LOOP;
END $$;

-- Drop old enum column
ALTER TABLE shopping_items DROP COLUMN category;

-- shopping_lists
CREATE TABLE shopping_lists (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  home_id uuid NOT NULL REFERENCES homes(id) ON DELETE CASCADE,
  name text NOT NULL CHECK (char_length(trim(name)) BETWEEN 1 AND 100),
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX idx_shopping_lists_home_id ON shopping_lists(home_id);
ALTER TABLE shopping_lists ENABLE ROW LEVEL SECURITY;
CREATE POLICY "home members full access" ON shopping_lists
  USING (EXISTS (SELECT 1 FROM home_members hm
    WHERE hm.home_id = shopping_lists.home_id AND hm.user_id = auth.uid()))
  WITH CHECK (EXISTS (SELECT 1 FROM home_members hm
    WHERE hm.home_id = shopping_lists.home_id AND hm.user_id = auth.uid()));
GRANT SELECT, INSERT, UPDATE, DELETE ON shopping_lists TO authenticated;

-- shopping_list_items
CREATE TABLE shopping_list_items (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  list_id uuid NOT NULL REFERENCES shopping_lists(id) ON DELETE CASCADE,
  name text NOT NULL CHECK (char_length(trim(name)) BETWEEN 1 AND 120),
  category_id uuid REFERENCES shopping_categories(id) ON DELETE SET NULL,
  quantity numeric(10,2) NOT NULL DEFAULT 1 CHECK (quantity > 0),
  unit shopping_unit NOT NULL DEFAULT 'un',
  notes text CHECK (char_length(notes) <= 200),
  reorder_months int CHECK (reorder_months > 0 AND reorder_months <= 24),
  last_added_at timestamptz,
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX idx_shopping_list_items_list_id ON shopping_list_items(list_id);
ALTER TABLE shopping_list_items ENABLE ROW LEVEL SECURITY;
CREATE POLICY "home members full access" ON shopping_list_items
  USING (EXISTS (
    SELECT 1 FROM home_members hm
    JOIN shopping_lists sl ON sl.home_id = hm.home_id
    WHERE sl.id = shopping_list_items.list_id AND hm.user_id = auth.uid()
  ))
  WITH CHECK (EXISTS (
    SELECT 1 FROM home_members hm
    JOIN shopping_lists sl ON sl.home_id = hm.home_id
    WHERE sl.id = shopping_list_items.list_id AND hm.user_id = auth.uid()
  ));
GRANT SELECT, INSERT, UPDATE, DELETE ON shopping_list_items TO authenticated;
```

- [ ] **Step 5: Create `src/features/shopping/actions-lists.ts`**

Seven actions. Standard pattern for each. For `applyList`:
1. Parse `list_id` from fd
2. Verify list belongs to home: `.from("shopping_lists").select("id").eq("id", listId).eq("home_id", homeId).maybeSingle()` — null → "Lista não encontrada."
3. Fetch items: `.from("shopping_list_items").select("name, category_id, quantity, unit, notes").eq("list_id", listId)`
4. If `!items?.length`, return `{ status: "error", message: "Lista vazia." }`
5. Batch insert: `.from("shopping_items").insert(items.map(i => ({ home_id: homeId, name: i.name, category_id: i.category_id ?? null, quantity: i.quantity, unit: i.unit, notes: i.notes ?? null, is_purchased: false })))`
6. Update `last_added_at`: `.from("shopping_list_items").update({ last_added_at: new Date().toISOString() }).eq("list_id", listId)`
7. `revalidatePath("/compras")`
8. Return `{ status: "success", message: \`${items.length} itens adicionados à lista de compras.\` }`
